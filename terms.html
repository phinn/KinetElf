KinetElf 用户协议

生效日期:2026-09-02 · 适用于 iOS 应用「KinetElf」

1. 协议范围

本协议是你与 KinetElf 开发者之间就使用本 App 达成的约定。下载即表示同意本协议。本协议受 Apple 标准最终用户许可协议(EULA)约束,以下条款为补充。

2. 服务内容

KinetElf 是一款本地优先的口袋精灵陪伴 App:离线性格引擎永久免费且功能完整;可选配置你自己的第三方大模型 API Key 以获得更聪明的对话。免费用户每日含 50 条云端对话额度(仅在使用自配云端服务时计数),超出后当日自动降级为离线引擎,次月/次日自动恢复。

3. 自动续期订阅条款

  • 「Pro 月度」「Pro 年度」为自动续期订阅:确认购买后从 Apple 账户扣款,订阅期内解锁云端对话不限量。
  • 订阅到期前 24 小时内自动续费,费用按所选周期从你的 Apple 账户扣取。
  • 如需取消,须在当前订阅期结束前至少 24 小时操作:打开 系统设置 → Apple 账户 → 订阅 选择取消;取消后可继续使用至本期结束。
  • 「Pro 买断」为一次性付费,永久有效,无续费。
  • 免费层(离线引擎 + 每日 50 条云端额度)不因订阅到期而被削弱或锁定。

4. 退款

购买与退款由 Apple 处理,可在 reportaproblem.apple.com 申请。

5. 可接受使用

  • 你通过自配第三方服务发送的内容,须遵守该服务商的使用条款;因违反产生的账号限制由你与该服务商之间解决。
  • 不得利用本 App 生成违反法律法规或侵犯他人权益的内容。
  • 近场碰一碰功能仅交换精灵数据,请勿用于其他用途。

6. 免责声明

精灵对话由 AI 生成,可能存在错误、幻觉或不恰当内容,不构成任何专业建议。第三方服务商的可用性、价格变更不在开发者控制范围内;你自行配置的 API Key 使用产生的费用由你与服务商之间结算。

7. 协议变更

变更将在本页更新生效日期;继续使用视为接受更新后的协议。
